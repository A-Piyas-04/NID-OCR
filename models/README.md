# Models

Exported / checkpoint model weights are **not** committed to Git.

On Kaggle they are written under:

```text
/kaggle/working/output/
```

Typical targets after fine-tuning:

- detection export directory from `PP-OCRv5_server_det`
- recognition export directory from `PP-OCRv5_server_rec`

Persist useful exports as private Kaggle Dataset versions if needed between sessions.
